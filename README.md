# GAT — Diário de Atividades e Análise do Tempo

Etapa 0: especificação inicial. Não contém aplicação implementada.

## Objetivo
Registro espontâneo de atividades do cotidiano, iniciado no ato da ação e finalizado posteriormente, com análise do tempo por categorias. Planejamento e agendamento são opcionais, não o núcleo do produto.

## Referência
Planilha Pasta2.xlsx, aba Registro; cabeçalho na linha 15; dados a partir da linha 16. A planilha original não foi modificada.

## Tecnologias previstas
FastAPI, Python, SQLite, SQLAlchemy/Alembic, HTML/CSS/JS modular, Chart.js; pytest, Vitest, Playwright; GitHub Actions.
